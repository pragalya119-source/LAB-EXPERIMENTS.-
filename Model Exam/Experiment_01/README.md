# Experiment 01 – RAPTOR Flowchart: Reverse a Number

The manual question asks for a RAPTOR flowchart that reverses a positive integer, with sample `1234 -> 4321`, and an analysis of loop values, complexity and trailing zeroes.

## Run the included reference implementation
```bash
python Source_Code/reverse_number.py
```
Try `1234`, `1221` and `1200`.

## RAPTOR implementation
Build the flowchart in RAPTOR using Input, Assignment, Loop, Output symbols. The flowchart image in `Output_Screenshots` is an algorithm reference, not a screenshot of the RAPTOR application. Recreate and run it in RAPTOR for the software-specific evidence required by your faculty.

# CSA10 Software Engineering – Model Practical Set 7

This package contains **only the four questions** shown in the user's Model Practical – Set 7 image, not all 30 experiments.

1. `Experiment_01` – RAPTOR Flowchart: Reverse a Number
2. `Experiment_02` – Containerize a Node.js Express Notes Application
3. `Experiment_03` – GitHub Repository Setup with `.gitignore` and README
4. `Experiment_04` – Smart Parking Management System – Use Case Diagram

Each folder contains `Source_Code/`, `Output_Screenshots/`, `README.md` and `Experiment_Details.txt`.

## Evidence / execution limitations
- Q1: Python reference implementation executed and flowchart image rendered. The diagram is an algorithm reference; run the flowchart in RAPTOR for RAPTOR-specific evidence.
- Q2: Express source and Dockerfile are included. Node service tests and JavaScript syntax validation were executed. Docker is not installed here and npm registry access was unavailable, so the Express server was not launched and Docker build/run or Docker Hub push was not performed. Run `npm install`, `npm test`, `npm start` and Docker commands on your computer.
- Q3: a local Git repository was initialized and two commits created; commit history and clean status were captured. No GitHub remote URL/account was supplied, so no remote push was performed.
- Q4: UML use-case diagram rendered from included model source. It is not a screenshot of Umbrello/StarUML. Recreate it in the CASE tool if native-tool evidence is required.

No account credentials, remote push, Docker Hub publication or cloud deployment are fabricated. Replace placeholders with your own account details and capture platform screenshots where required.

See each experiment README for run instructions. Python 3.10+ and Node.js 20+ are recommended. Docker is required for Q2 container execution.

# Experiment 04 – Smart Parking Management System: Use Case Diagram

Actors: Driver, Parking Attendant, Administrator and Payment Gateway.

The driver searches slots, reserves, pays and enters parking. The parking attendant handles lost tickets. The administrator configures tariffs and views occupancy reports. The payment gateway is an external payment service.

Diagram source: `Source_Code/Smart_Parking_Use_Case.puml`

With Java and PlantUML installed:
```bash
plantuml -tpng Source_Code/Smart_Parking_Use_Case.puml
```
Alternatively, recreate the model manually in Umbrello / StarUML. The PNG is rendered from the UML model source, not a screenshot of the CASE-tool interface. Recreate it in your CASE tool if a native-tool screenshot or project file is required.

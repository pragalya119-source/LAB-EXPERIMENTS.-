# Experiment 1 – Kanban Board

## Aim

To create a Kanban Board for the Tripora – Bus Booking System to visualize tasks and simulate the workflow using Trello.

## Tool Used

Trello

## Workflow

To Do → In Progress → Done

## Sample Tasks

1. Design the Tripora Homepage
2. Design the Passenger Login Page
3. Create the Bus Search Feature
4. Develop the Seat Selection Feature
5. Create the Project Database Design

## Result

A Kanban Board was successfully created in Trello for the Tripora – Bus Booking System. The tasks were organized into To Do, In Progress, and Done columns, and moved across the columns to simulate the project workflow and track task progress.

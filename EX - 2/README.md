# Software Engineering Lab

## Experiment 2 – Bus Ticket Booking System

### Aim

To design a prototype for a Bus Ticket Booking System using Figma.

### Tool Used

Figma

### Workflow

Search Bus → View Bus Details → Select Seats → Enter Passenger Details → Confirm Booking

### Features

1. Search buses by source, destination, and travel date.
2. Display bus numbers, timings, types, and ticket prices.
3. Provide exactly 55 seats per bus.
4. Separate Upper Deck and Lower Deck seat layouts.
5. Include sleeper and sitting seat options.
6. Display available, booked, and selected seats.
7. Show boarding points and dropping points.
8. Calculate the total ticket fare.
9. Display passenger and booking details.

### Figma Link

https://handle-lean-01032030.figma.site/
### Result

To design a Bus Ticket Booking System prototype using Figma with bus search, seat selection, and booking features.

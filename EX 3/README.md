# Experiment 3 – E-Commerce Mobile Shopping App

## Aim
To design and develop a mobile shopping application prototype using Figma Make to present different user interface designs and gather stakeholder feedback and approval.

## Tool Used
Figma Make

## Description
ShopEase is a mobile e-commerce shopping application designed to provide users with a convenient and user-friendly online shopping experience. The application includes multiple product categories, product listings, search functionality, filters, sorting options, product details, shopping cart, wishlist, offers, and user account features.

The prototype is designed to demonstrate the major features of an online shopping platform with a simple navigation system, attractive interface, and easy product browsing.

## Key Features
1. Multiple product categories.
2. Product search and filtering.
3. Product details and ratings.
4. Add to Cart functionality.
5. Wishlist management.
6. Special offers and discounts.
7. User profile and order management.
